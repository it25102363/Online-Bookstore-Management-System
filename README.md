# Online Bookstore Management System

### Java OOP Group Project

An Online Bookstore Management System developed using **Java, Spring Boot, MySQL, HTML, CSS, and Thymeleaf**.

This project aims to provide an online platform where customers can browse books, manage their shopping activities, and track their orders. The system also provides administrative features for managing bookstore operations.

## Technologies Used

- **Programming Language:** Java
- **Backend Framework:** Spring Boot
- **Frontend:** HTML, CSS, Thymeleaf
- **Database:** MySQL
- **ORM:** Spring Data JPA / Hibernate
- **Security:** Spring Security
- **Build Tool:** Maven
- **IDE:** IntelliJ IDEA
- **Version Control:** Git and GitHub

## Main System Modules

**1. User Authentication and Management**
- Customer registration and login
- User account management
- Role-based access for customers and administrators

**2. Book Management**
- Display book information
- Manage book inventory
- Add, update and remove books

**3. Cart Management**
- Add and remove books from the cart
- Update shopping cart quantities
- Calculate cart totals

**4. Order Management**
- View customer orders
- Display order details
- Manage order statuses
- Cancel eligible orders
- Delete cancelled orders

**5. Wishlist Management**
- Add books to the wishlist
- View saved books
- Remove books from the wishlist

**6. Reviews and Feedback**
- Manage customer reviews
- Collect feedback about books and services

## Object-Oriented Programming Concepts

The project is designed around the following OOP principles:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

It also follows layered application architecture with controllers, services, repositories and entity classes.

## Repository Branches

The project uses separate development branches to manage individual contributions.

| Branch | Purpose |
|---|---|
| `main` | Main project documentation and integration base |
| `feature/user-authentication` | User authentication and management |
| `order-management` | Order processing and management |
| `book-management` | Book inventory management |
| `wishlist-management` | Customer wishlist management |
| `feature/reviews` | Reviews and feedback development |
| `cart-management` | Shopping cart management |

Additional feature branches may be created as development progresses.

## Project Development Status

**Status: Under Development**

Each module is developed and tested separately before integration into the main branch.

The final system will be completed by integrating the individual modules and performing system-level testing.

## Team Contributions

This project is developed as a university group assignment. Team members contribute through separate Git branches, with individual commits used to track development work.

## Project Purpose

This project demonstrates practical knowledge of Java Object-Oriented Programming, database connectivity, web application development, layered architecture, testing, and collaborative software development using GitHub.
